# Contributing to NXYMusic

Thanks for helping improve NXYMusic. Before starting a larger change, check the open issues or open an issue to discuss the approach. Branch from `main`, keep changes focused, and follow the Kotlin and Compose conventions used by nearby code.

For code changes, include or update tests where practical and describe the device or platform used to test the change. Update the relevant Compose resource files when user-facing text changes, and keep translations consistent with the default English strings.

Translations can be proposed in pull requests that update the appropriate resource files. Do not include API keys, signing credentials, personal data, or other secrets in commits or issue attachments.

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for the community standards. Pull requests should explain what changed, why it is needed, and how it was tested.
